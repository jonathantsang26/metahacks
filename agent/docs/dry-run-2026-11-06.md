## Bug found and fixed

**Long chats failed with a 400.** From about the third message in one chat, every run died with
`Invalid signature in thinking block. The block is bound to a different conversation`. Cause: Agent-Native's
Observational Memory compacts the thread (it fires early here because the forecast and plan tool results are
large), even in the middle of a tool loop. That changes the messages before an earlier signed thinking block,
and the API rejects it. Fix: `patches/@agent-native__core@0.225.1.patch` (applied by pnpm through
`pnpm-workspace.yaml`) sends `thinking.block_binding.prefix_mismatch_behavior: "drop_block"` with the
`thinking-binding-controls-2026-08-01` beta header, so the API drops the stale block instead of failing.
Verified: the same chat then ran four more turns (briefing, briefing edit, next-hour plan) with no error.

## Script changes to make

1. **Start time.** The checklist URL says `t=2025-01-08T23:30:00Z` (3:30 PM). The demo hour is 16:00Z (8 AM PST):
   `/incident?fire=eaton&t=2025-01-08T16:00:00Z`. Narration in beats 1 to 3 and 9 should say 8 AM, then 9 AM.
2. **Beat 4 numbers vary between runs.** A first pass gave 38% with 500 to 600 m radii; this pass gave 62% with
   1,300 to 1,500 m radii. Read the numbers off the screen on the take; do not script them.
3. **Beat 5.** With big radii a drag barely moves the score. Say "the score updates right away", not "goes up".
   Grab the black dot itself; a drag that starts off the dot pans the map.
4. **Beat 6.** Better P2: `Move the drone I selected onto the biggest flyable gap in the front near homes, keep
   D1 where it is, and tell me what that does to the score.` In the first pass this moved D3 and took coverage
   from 33.4% back to 38.4%. If no flyable gap is left, the agent says so and moves nothing, which is honest but
   quiet on camera.
5. **Beat 8 (refused number).** No paragraph was dropped in either pass; the agent cites carefully. Two ways to
   show the check on camera: (a) ask for something the data cannot support ("how many homes will burn") and show
   the agent refuse; (b) edit a number by hand (62% to 75%), press Save, and show UNVERIFIED.
6. **Beat 10.** Baseline is "evenly spaced drones". Numbers from this pass: 68% vs 61% of 157 ha.
7. **Beat 11.** Keep it: it shows wind grounding most of the next hour (11%, D1 grounded), which is an honest
   result. Or cut it for time.
8. **Guide.** After the agent's first plan the guide jumps to step 6 (because the briefing already exists), and
   it stays on step 6 after Approve.
